# Architecture Decision Records

## Purpose

Index accepted decisions and their evidence.

## Audience

Agents making architectural changes and reviewers.

## Update when

Add an ADR when a change affects boundaries, external contracts, state ownership,
fallback order, data format or recovery policy.

## Format

Each ADR records context, decision, consequences, alternatives, status and
source/runtime evidence. Accepted ADRs are historical decisions; a newer ADR
supersedes them instead of rewriting history.
