# Prompt Library

## Purpose

Provide reusable prompts that route agents to repository-specific evidence.

## Audience

AI agents and maintainers preparing a task.

## Update when

Update when a repeatable task pattern or required evidence changes.

## Prompts

Implementation, refactoring, bug fixing, test generation, review, architecture,
dependency analysis, log investigation, documentation and DLL release prompts
are stored in this directory.
