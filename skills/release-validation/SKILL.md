# Release Validation Skill

## Use when

Building, packaging, committing or pushing a plugin release.

## Read first

`docs/release.md`, `workflows/release.md`, `rules/release.md` and
`.agents/checklists/release.md`.

## Method

Check branch, version markers, external references, x64/net48 build, Data
content, manifest, changelog, ignored artifacts and commit SHA.

## Output

Exact command/results, artifact metadata, unavailable checks and remote commit.
