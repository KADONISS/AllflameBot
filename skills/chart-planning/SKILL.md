# Chart Planning Skill

## Use when

Changing Chart terrain, topology, hybrid frontier or exploration behavior.

## Read first

`docs/modules/chart.md`, `knowledge/map-model.md`,
`architecture/boundaries/map-coordinate.md` and `rules/navigation.md`.

## Method

Confirm area hash, spawn, coordinate space, snapshot dimensions, path validation,
planner priority and fallback. Never infer a world coordinate solely from a row
or column without evidence.

## Output

Planner ownership, target transformation, fallback behavior, logs and fixture
requirements.
