# Documentation Rules

## Purpose

Keep AI and human documentation useful without duplicating source behavior.

## Audience

Agents changing code or docs.

## Update when

Update when the documentation structure or source-of-truth policy changes.

## Rules

- Every durable document states purpose, audience, update trigger and dependencies.
- Document current behavior separately from target architecture.
- Link to source evidence for non-obvious claims.
- Update architecture when ownership or dependencies change.
- Update knowledge when a business rule or limitation is confirmed.
- Update an ADR for a deliberate architectural decision.
- Do not copy long changelog histories into architecture pages.
