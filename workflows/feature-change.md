# Workflow: Feature Change

## Purpose

Standardize implementation of a behavior change.

## Audience

Developers and AI agents.

## Update when

Update when the required change sequence changes.

## Steps

1. Route context and read the module/feature documents.
2. Map current task, state, adapter and fallback ownership.
3. Define postcondition and regression evidence.
4. Implement the smallest coherent change.
5. Update tests, logs, docs, ADR/knowledge and changelog as needed.
6. Build, inspect diff and report limitations.
