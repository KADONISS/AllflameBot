# Workflow: Documentation Update

## Purpose

Keep documentation synchronized without creating competing truths.

## Audience

Agents changing docs or code behavior.

## Update when

Update when the documentation maintenance process changes.

## Steps

1. Identify current source of truth.
2. Compare existing docs, source and changelog.
3. Update the smallest owning document.
4. Add cross-links rather than duplicating large explanations.
5. Update required-reading routes if the boundary changed.
6. Check links and metadata fields.
